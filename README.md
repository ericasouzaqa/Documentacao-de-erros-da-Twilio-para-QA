# Dicionário de Erros Twilio

Base de consulta de códigos de erro da Twilio, criada para apoiar atividades de **QA, testes de integração e investigação de falhas**.

## Objetivo

Facilitar a consulta e identificação de erros retornados pela Twilio durante os testes.

## O que contém

* Códigos de erro
* Descrições
* Informações para consulta durante a análise de falhas

## Como utilizar

1. Abra uma das planilhas disponíveis.
2. Localize o código retornado pela integração.
3. Consulte a descrição correspondente.
4. Utilize a informação como apoio à investigação.

## Aplicação em QA

Pode ser utilizado para:

* Testes de integração;
* Testes de cenários negativos;
* Análise de respostas de API;
* Investigação de falhas;
* Documentação de bugs;
* Validação do tratamento de erros.

## Exemplos de cenários

**Erro durante o envio de mensagem**
Consultar o código retornado e verificar o comportamento esperado da aplicação.

**Falha de integração**
Identificar o código recebido e utilizá-lo como apoio à investigação.

**Cenário negativo**
Validar se a aplicação trata corretamente o erro retornado pela Twilio.
